# Guchibo MVP 仕様書

プロジェクトメンバー向けに、現時点でGuchibo MVPが「何をするアプリなのか」「何ができて、何がまだできないのか」をまとめたものです。コードの実装状況に合わせて随時更新してください。

最終更新: このドキュメントは `guchibo-app` リポジトリのMVP初版と同時に作成されました。

## 1. サービス概要

- ブランドワード：「孤独に、会話という居場所を。」
- コンセプト：自己肯定感を高めるAIチャットサービス（`開発/Guchibo_MVV.pdf` 準拠）
- 存在意義：孤独な人にいつでも支えを届ける

Guchiboは「相談する」アプリではなく、「吐き出す→整理される→受け止めてもらう→少し軽くなる」という体験を提供する対話アプリです。分析・指導・診断は行いません。

## 2. ターゲットユーザー

MVPでは以下の2層を想定しています（元の要件定義では子育て中の母親が主軸でしたが、開発方針のすり合わせで対象を広げました）。

- 子育て中の母親（25〜40代目安）：孤立しやすく、感情の波が大きく、時間が細切れ。共感・安心感を重視。
- 社会人になったばかりの人：悩みを抱えやすいが、まだ相談先が定まっていない層。

そのため、オンボーディングやシステムプロンプトの文言は「子育てママ向け」に限定しない、やや一般化した言い回しにしています。

## 3. AI対話の設計方針

- **軸：感情受容型**（要件定義V2ベース）。「認知の歪みの検出・再解釈」のようなCBT的な踏み込みは行いません。
- 基本フロー：①感情の受容 → ②状況の言語化 → ③努力の承認 → ④必要なら小さな整理・提案 → ⑤最後にひとつだけ問いかけ
- してはいけないこと：説教、正論での指摘、診断名の断定、ポジティブの強制
- 出力ルール：日本語・150字程度・箇条書きは必要な時だけ・質問は最後に一つまで
- 実装：`lib/systemPrompt.ts`（元ネタは `開発/システムプロンプト.docx` を、ターゲット拡大に合わせて一般化したもの）
- 使用モデル：Anthropic Claude（デフォルト `claude-sonnet-5`。`.env` の `ANTHROPIC_MODEL` で変更可）

## 4. 安全設計（危機介入）

- `lib/crisis.ts` にキーワードリストを保持し、ユーザーの発言に含まれていないかをクライアント側・サーバー側の両方でチェックします。
- 検出キーワード例：「死にたい」「消えたい」「自殺したい」「もう限界」「リスカ」「ODした」など（全リストはコード参照）。
- 検出された場合は、AIの返信を待たずに危機介入画面（相談窓口の案内）へ即座に遷移します。
- 案内する窓口：よりそいホットライン（0120-279-338）、いのちの電話（0570-783-556）、救急（119）。
- **開発・テスト時は `EXPO_PUBLIC_CRISIS_TEST_MODE=true` でダミー番号に切り替え可能**（誤発信防止。本番では必ず解除）。
- 「AIは医療行為・診断を行いません」という位置づけを、FAQ画面・システムプロンプト双方に明記しています。

## 5. 画面ごとの現状機能

| 画面 | 実装状況 | 内容 |
|---|---|---|
| 起動（スプラッシュ） | ◎実装済み | ロゴ表示後、登録済みならホームへ、未登録ならオンボーディングへ自動遷移 |
| オンボーディング（3枚） | ◎実装済み | スキップ可。「はじめる」で登録へ |
| 登録 | △一部実装 | ニックネーム登録は実際に機能。**Apple/Googleログインはボタンのみ（未接続）** |
| ホーム（今日の気分入力） | ◎実装済み | 気分4種・きっかけタグ・自由メモを入力し、そのままチャットへ引き継ぐ |
| AIチャット | ◎実装済み | Claude APIとリアルタイムに対話。危機ワード検出も同時に動作 |
| きろく（履歴） | ◎実装済み | 会話一覧・検索・詳細閲覧。**端末内保存のみ（複数端末同期なし）** |
| 危機介入 | ◎実装済み | 相談窓口の案内・電話発信リンク・「Guchiboと話を続ける」導線 |
| サブスク（Guchibo Plus） | △UIのみ | プラン選択・案内UIは完成。**実際の決済（Stripe等）は未接続**、ボタン操作でローカルのプラン状態のみ切り替わるデモ動作 |
| 設定 | △一部実装 | プロフィール表示、記録の書き出し（Web版はクリップボードコピー）、データ削除は実装済み。**通知・リマインド／アプリのロックは未実装（ボタンのみ）** |
| FAQ / 使い方 | ◎実装済み | 静的なQ&A |

## 6. マネタイズ（現状の実装）

- 無料プラン：月30回まで会話可能（超過するとサブスク画面へ誘導）
- Plus（有料）プラン案内：年額プラン ¥19,800/年（7日間無料）、月額プラン ¥1,980/月
- **注意**：現状は決済導線のUIのみで、実際の課金・請求は発生しません。本番展開には決済基盤（Stripe / RevenueCat 等）の統合が必須です。

## 7. 現時点でできないこと（MVPスコープ外）

- Apple / Google ログイン（実OAuth連携）
- 実際のサブスクリプション決済
- 会話・気分記録のサーバー保存・複数端末同期
- プッシュ通知・アプリロック（生体認証）
- 危機検出の精度向上（現状はキーワード一致のみ。表現の揺れには対応していません）

技術的な背景や今後の実装課題については `docs/DEVELOPMENT.md` を参照してください。
